# 两孩游戏统一托管包

准备日期：2026-09-12。状态：文件已准备；尚未发布腾讯云、尚未绑定域名、尚未实测中国大陆普通网络、尚未接通自动同步。

## 已收录

- Kenton World：哥哥 v13，取自当前 Library 文件版本 2。
- Eddey World：弟弟游戏大厅第 8 版中的牧野最新副本，包含九格物品栏拖放。
- 后室：CNB 独立仓库 main 当前版本，五层逃离。

site/games.json 保存本轮来源与逐文件校验值。历史早期方块版本不在大厅展示，原站、原文件和旧仓库均未删除或覆盖。此次只迁移副本，不改玩法。

## 发布与持续更新

把 site 文件夹的内容完整放到腾讯云静态网站目录；也可直接把 site 打包上传 EdgeOne。网站首页是 site/index.html。后台脚本、README、rollback 不属于公开网站目录。

固定入口：/games/kenton/index.html、/games/eddey/index.html、/games/backrooms/index.html。后续更新只替换对应游戏，其他入口保持原样。

更新脚本（供执行助手使用）：python3 update_game.py kenton 新游戏.html --version v14。弟弟用 eddey；后室用 backrooms。脚本检查静态外部资源、现有资源路径及方块存档身份，更新前备份并写后核对哈希。动态联网行为和玩法兼容性仍须另行检查。脚本只准备文件，不会发布，也不是已经配置好的自动同步。

后续每次游戏修改完成，需要将受测通过的最新版交到同一个站点发布目录。要实现无人值守自动发布，还须为独立游戏项目配置有权限的发布通道与触发器；本轮没有假设该通道存在。

## 腾讯云接入现状

2026-09-12 实测现有执行器 tencent-sg-01 在线，主机 VM-0-17-ubuntu，区域新加坡。当前已连接工具可查健康和管理 CNB 文件，没有网站目录写入、Web 服务配置或 DNS 管理能力。没有尝试绕过工具白名单。

历史验收资料记载 Windows Codex 有 ssh eddey-tencent-sg 接入；本会话没有该 Windows SSH 环境。可在该已有环境继续部署，或连接可访问这台服务器的远程终端。只增加游戏站点，先检查现有服务、监听端口、配置与恢复路径，不覆盖股票、学习、备份和私人 MCP。

syncwatchhub.com 是历史已有域名记录，当前权威 DNS 和备案状态本轮未获得。正式绑定前需读取；不得改动已有根域名、relay、market 的业务。游戏使用单独子域名，并在新加坡普通线路与大陆节点之间按实际国内联网结果选择。

验收要分别确认：上传文件与哈希、Web 服务路由、HTTPS、关闭 VPN 的国内宽带和手机流量、游戏进入与资源完整、存档导入导出，以及替换新版后的固定网址刷新。当前不把服务器在线等同于游戏可访问。

## 存档

哥哥保留 mcv7-，弟弟保留 mcv82-，没有修改已有存档格式。浏览器数据按网址隔离，因此玩家先在旧入口导出存档码，再在新入口导入。保留旧入口直到新入口验收完成。后室保持原有行为，不额外宣称具备云存档。

## 本地查看

python3 -m http.server 8000 --directory site

随后在同一电脑浏览器打开 http://localhost:8000。游戏使用 WebGL，需要支持 WebGL 的浏览器。
